## 🚀 Run It Locally

Want to explore the store on your own machine? Easy!

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Open the project folder:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Make sure `ECOM.html` and `style.css` are in the same folder.

4. Open `ECOM.html` in your browser.

5. Enjoy your shopping experience. Your wallet is safe. Probably. 💸

## ⚠️ A Little Reality Check

ShopEasy is currently a **front-end demo**, not a fully functional e-commerce platform.

- 🛒 Cart and Add to Cart buttons are visual elements.
- 🔍 The search bar does not yet filter products.
- 📝 The signup form does not store account information.
- 💳 No payment gateway, database, or backend is connected.

Basically, you can admire the products without accidentally spending your savings. 😌
